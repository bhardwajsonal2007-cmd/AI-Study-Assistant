AI Study Assistant

An AI-based study assistant that analyzes student academic data and provides personalized study recommendations.

About the Project

AI Study Assistant is a Python and Machine Learning based project designed to help students understand their academic performance.

The application takes marks, daily study hours, and attendance as input and provides performance analysis, identifies the weaker subject, and gives personalized study recommendations.

Features

- Student performance analysis
- Performance prediction using Machine Learning
- Weak subject identification
- Attendance analysis
- Personalized study recommendations
- Daily study plan
- Marks comparison graph
- Interactive web interface using Streamlit

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib
- Git & GitHub

How It Works

1. Enter the student's marks in Maths, Python, and Machine Learning.
2. Enter daily study hours and attendance percentage.
3. The application analyzes the input data.
4. A Machine Learning model predicts the student's performance.
5. The application identifies the focus subject.
6. It provides personalized study recommendations and a study plan.
7. A graph displays the marks comparison.

Project Structure

- "app.py" – Streamlit web application
- "data.py" – Data analysis and Machine Learning implementation
- "main.py" – Basic study assistant logic
- "students_data.csv" – Student dataset
